Content

One engine behind every series

Motion Graphics is the main series; hardware, everyday tech and gaming are formats of the same engine.

01
Main series

Motion Graphics

Narrated kinetic-typography explainers of 62-90 s: big words, one accent phrase, counters, code, bars, cards and an outro. Always vertical, in English, in one of fourteen blue looks. Two kinds: tech curiosities and games (an engineering fact told over real footage).

main.py --export-only
02

Hardware Deep Dive

Silicon, memory, storage, networking and engineering explained with mechanism and real figures. The mouse cursor only appears as an accent.

--motion-format hardware
03

Everyday Tech

Small everyday tech mysteries hosted by the mouse cursor, a character that uses the screen like a person: it selects the key phrase as the narrator says it, pulls progress bars, carries chips into a tier list and presses settings, only when that means something.

--motion-format simple
04

Gaming

A Motion game video. Banked game scripts go first, told over screenshots of the game and credited in the description; then source-grounded videos with real footage; a hardware video when neither is possible.

main.py --category 2
05

Automatic

The AI picks the category with the longest rest, using the history database and retention analytics, so the channel never repeats itself.

main.py --category 4
Signature element

A cursor that acts like a person

The mouse pointer is a character of the whole Motion engine, used only when it does something that means something: no browser tab to introduce the topic, no hovering, no waiting. Any scene can carry a cursor action, and the pointer acts on what is really on screen: it measures the tagged elements of the scene.

selectdragclicktoggle

Select highlights the key phrase as it is spoken, drag pulls a progress bar or carries a chip into its tier, click presses a setting.

Flip Airplane Mode and watch Wi-Fi and Bluetooth switch off, exactly like the real thing. (Watch the demo.)

Looks and retention

No two videos look the same

Every video gets one of fourteen blue looks, and this page wears eight of them: the colours change as you scroll. Six retention devices are enforced on every script.

01
Fourteen looks

A new blue every time

Own palette, background, typeface, camera, transitions, HUD and captions. The next look never repeats the last three.

Run it

Everyday commands

Copy, paste, done.

Set it up

Python environment, then the Remotion project.

python3 -m venv .venv && .venv/bin/pip install -r requirements.txtcd remotion_studio && npm install && cd ..

Make a video

The main series alternates curiosity and game. Render only.

.venv/bin/python main.py --export-only

Pick a format

Myth, tier, what if, evolution, versus, fix it, decoded and more.

.venv/bin/python main.py --motion-format versus --export-only

Game video

An engineering fact told over real footage.

.venv/bin/python main.py --motion-kind game

Four for tomorrow

Picked from your analytics. Drop --plan to render and schedule.

.venv/bin/python scripts/genera_batch.py --plan

Check the numbers

The retention report and the style check of the script banks.

.venv/bin/python scripts/report_retention.py.venv/bin/python scripts/lint_retention.py

Tweak the design

Preview the Remotion composition live.

cd remotion_studio && npx remotion studio

Nov 2026

Hooks that start a fight, rankings that end on the winner

Every video now opens on its title at frame 0 and states a conflict instead of a topic. Tier lists cover the S-tier pick with a "?" until the last scene, stamp TOP PICK and WORST as they land, and show the figure behind every rank. The outro asks one A-or-B question, drawn as two vote cards.

Nov 2026

Real prices, a health check and the latest videos here

"Which one is worth it today?" tier lists are built from that day's shop prices. A health check runs before every batch and reports token, voice credits and disk. This page now shows the newest Shorts, refreshed every fifteen minutes.

A softer site that changes look as you scroll

The portal wears eight of the videos’ blue looks and blends from one to the next while you read, with softer colours, hairline borders, long shadows and slower motion.
